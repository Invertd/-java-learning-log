# java-learning-log

> **目标：2028 届 Java 后端，进广东（深圳优先）。**
> 当前：2026-11-03 起步 ｜ 终点：2027 年秋招拿到 15k+ offer

这个仓库不是笔记仓库，是**打卡仓库**。每天做完一项任务就勾一项，并产生一次 commit。
commit 曲线本身就是证据 —— 面试官点开 GitHub 看到的是"一个连续做了 8 个月的人"还是"一个周末传了 500 个文件的人"，一眼就能分辨。

---

## 怎么用（3 条命令）

```bash
# 1. 看今天要做什么
python tools/tick.py

# 2. 做完第 3 项，勾掉（自动写日志 + commit + push）
python tools/tick.py 3

# 3. 看总进度
python tools/tick.py --status
```

其他用法：

```bash
python tools/tick.py 2 5 7      # 一次勾多项
python tools/tick.py --day 05   # 看/操作第 05 天
python tools/tick.py 3 --no-push
python tools/tick.py --undo 3   # 勾错了撤销
```

> 勾了但没 push 成功？手动 `git push` 就行，日志和 commit 都在本地。

## 目录

```
days/      48 个每日任务文件（2026-11-03 → 2026-12-20，W1–W7）
weeks/     考试周 + 寒假（10 个周文件，任务按周列，自己拆到天）
logs/      每天的打卡流水（tick.py 自动写）
notes/     八股笔记、源码分析（自己写）
src/       手写代码（MyHashMap、线程池、NIO server…）
tools/     gen_days.py 生成任务，tick.py 打卡
```

---

## 规则（三条，别改）

1. **每天至少 1 个 commit。** 空 commit 也行，但要真的做了什么。
2. **打卡 = 有代码 + 有 1 题 + 有 3 分钟口述录音。** 三个少一个都不算。
3. **连续 3 天没打卡，就说明强度排错了。** 降强度，不要硬扛然后放弃。
